## 1. Назначение

Tasker — локальный менеджер проектов и задач для одного пользователя. Он не
требует аккаунта, сервера в интернете или обязательного облака. Все проекты,
задачи, заметки и метаданные вложений лежат в обычной SQLite-базе; сами
вложения — в папке рядом с базой.

Обмен данными между компьютерами сделан **вручную**: пользователь нажимает
«Отправить на Диск» или «Скачать с Диска». Фоновой синхронизации и
автоматического слияния изменений нет.

Основные сценарии:

- вести проекты и задачи на канбан-доске;
- планировать задачи в календаре, в том числе на несколько дней;
- хранить заметки с фотографиями и документами;
- делать ZIP-копию базы вместе с файлами;
- переносить актуальную версию между компьютерами через Google Диск,
  Яндекс Диск или обычную папку.

## 2. Возможности

### 2.1 Проекты и канбан

- Неограниченное число проектов, у каждого свой цвет.
- Три колонки: **Срочно**, **Потом**, **Сделано**.
- Перетаскивание задач между колонками и внутри колонки.
- Счётчики активных и выполненных задач.
- Ручной порядок проектов и автосортировка по числу активных задач
  (включается в настройках).
- Редактирование названия и цвета проекта.
- Каскадное удаление проекта вместе с задачами, заметками и файлами.

### 2.2 Календарь

- Режимы **«Месяц»** и **«Неделя»**.
- Слева — задачи без даты; их можно перетащить в день.
- Задачу можно поставить на день, перенести на другой день или убрать из
  календаря.
- Задача может занимать диапазон дат: начало и конец, быстрые кнопки
  длительности 1–6 дней.
- Многодневная задача отображается одной непрерывной полосой, а не набором
  отдельных карточек.
- Строки календаря упаковываются: задачи, не пересекающиеся по дням, могут
  стоять на одной линии; пересекающиеся — друг над другом.
- Одна задача не разрывается между строками. При переходе на следующую
  неделю она сохраняет ту же строку.
- Ручной порядок строк: стрелки **↑/↓** или перетаскивание за ручку **⋮⋮**.
  Порядок хранится в базе и не пересчитывается автоматически.
- Растягивание за правый нижний угол полосы.
- Скрытие выходных, выполненных задач и названий проектов в настройках.

### 2.3 Заметки и файлы

- Заметки проекта в отдельной панели.
- Текст, ссылки, изображения и любые документы.
- Добавление файлов перетаскиванием, вставкой из буфера или через скрепку.
- Просмотр изображений в лайтбоксе.
- Ширина панели заметок запоминается.
- Вложения хранятся вне базы, в папке `<имя базы>_files`.

### 2.4 Локальная база и резервные копии

- Одна SQLite-база на всё приложение.
- Все изменения сразу фиксируются в базе.
- Путь к базе можно выбрать в настройках или задать при запуске.
- ZIP-копия содержит и базу, и все вложения.
- Копию можно скачать из интерфейса или сохранить рядом с базой
  (по умолчанию в `data/backups/`).
- Перед заменой данных с Диска создаётся локальная резервная копия.

### 2.5 Синхронизация

- Три ручных способа:
  1. папка Google Диска на компьютере;
  2. Google Drive API без приложения Google Диска;
  3. Яндекс Диск по OAuth-токену.
- Кнопки **«Отправить на Диск»** и **«Скачать с Диска»** в настройках.
- Быстрые кнопки **«На Диск»** и **«Скачать»** в боковой панели.
- Виджет актуальной версии над кнопкой «Настройки».
- Версия, устройство-автор, время последней синхронизации.
- Предупреждение, если после последней синхронизации появились локальные
  изменения.
- Обмен только по кнопке; автоматического слияния нет.

Подробная настройка каждого способа — в [connection.md](connection.md).
Инструкция для второго компьютера — в [new-device.md](new-device.md).

### 2.6 Интерфейс

- Светлая и тёмная темы.
- Адаптивная боковая панель.
- Закрытие последней вкладки завершает Tasker и корректно закрывает базу.
- Работа только через `127.0.0.1` по умолчанию.

## 3. Быстрый старт

### 3.1 Готовая сборка для Windows

1. Скопируйте `Tasker.exe` в папку с правами на запись, например
   `D:\Tasker`.
2. Запустите exe двойным щелчком.
3. Откроется браузер с приложением.
4. При первом запуске рядом с exe появится папка `data`:
   `data/tasker.db` и `data/tasker_files/`.
5. Для завершения закройте последнюю вкладку Tasker.

Консольного окна нет. Диагностический журнал:
`%APPDATA%\Tasker\tasker.log`.

Exe не подписан сертификатом, поэтому Windows SmartScreen может показать
предупреждение: «Подробнее» → «Выполнить всё равно». Прав администратора
приложение не требует.

### 3.2 Запуск из исходников

Нужен Python 3.10+ (проверено на 3.13 и 3.14). Внешних библиотек нет.

```powershell
cd D:\Projects\Code\tasker
python server.py
```

Или запустите `Tasker.bat`.

Сервер напечатает адрес, например `http://127.0.0.1:8765/`, и откроет
браузер. Если порт занят, будет выбран следующий свободный. Для остановки
закройте вкладку или нажмите `Ctrl+C` в консоли.

### 3.3 Перенос готовой папки

Можно перенести `Tasker.exe` вместе с папкой `data` на другой компьютер.
Тогда база и файлы будут доступны без синхронизации. Не запускайте две
копии приложения на одну базу одновременно.

## 4. Интерфейс

### 4.1 Боковая панель

- **Календарь** — общая доска всех проектов.
- **Проекты** — список с цветами и счётчиками.
- **Быстрая синхронизация** — виджет версии и кнопки «Скачать» / «На Диск».
- **Настройки** — календарь, проекты, база, синхронизация.
- Переключатель темы.

### 4.2 Виджет актуальной версии

Показывает:

- номер версии на Диске (`v1`, `v2`, ...);
- провайдера: «Яндекс Диск», «Google Drive API» или «Папка Google Диска»;
- устройство-автор;
- предупреждение «есть изменения», если локальная база изменялась после
  последней синхронизации.

Если синхронизация не настроена, кнопки неактивны, а нажатие на виджет
открывает настройки.

### 4.3 Доска проекта

- Три колонки, drag & drop.
- Двойной щелчок по карточке открывает редактор.
- В редакторе можно задать даты начала и конца, статус, описание.
- Карточка показывает диапазон дат, если задача многодневная.

### 4.4 Календарь

- Двойной щелчок по задаче — редактор.
- Двойной щелчок по пустому дню — новая задача на этот день.
- Перетаскивание полосы — перенос с сохранением длительности.
- Угол полосы — растягивание.
- Ручка **⋮⋮** или стрелки — порядок строк.

## 5. Данные и формат хранения

### 5.1 Расположение

По умолчанию:

```text
<папка Tasker>/
  Tasker.exe
  data/
    tasker.db
    tasker_files/
    backups/
```

При запуске из исходников — `data/tasker.db` рядом с `server.py`.
Путь к базе можно изменить в настройках; папка файлов переезжает вместе
с базой и называется `<имя базы>_files`.

### 5.2 Схема базы (версия 5)

| Таблица | Назначение |
|---|---|
| `meta` | Версия схемы и служебные значения |
| `projects` | Проекты: имя, цвет, позиция |
| `tasks` | Задачи: проект, описание, статус, позиция, даты, порядок в календаре |
| `messages` | Заметки проекта |
| `attachments` | Метаданные вложений и относительный путь к файлу |

Ключевые поля задачи:

- `scheduled_date` — дата начала;
- `scheduled_end_date` — дата окончания (NULL для одного дня);
- `calendar_order` — ручной порядок строк в календаре;
- `status` — `urgent`, `later`, `done`;
- `position` — порядок внутри колонки проекта.

Вложения:

```text
tasker_files/
  ab/
    <attachment-id>.bin
```

В базе хранится относительный `storage_path`; сами байты — только в файле.

### 5.3 Обновление схемы

При запуске база автоматически обновляется до актуальной схемы. Перед
переносом старых BLOB-вложений создаётся копия
`data/backups/pre-v3-...db`. Проекты, задачи и заметки не перезаписываются.

### 5.4 ZIP-копия

Архив `tasker-YYYY-MM-DD_HH-MM-SS.zip` содержит:

```text
tasker.db
tasker_files/...
```

Копию можно использовать для восстановления вручную или на другом
компьютере.

## 6. Синхронизация

### 6.1 Общие правила

- Обмен **только ручной**.
- «Отправить» заменяет версию на Диске локальной.
- «Скачать» заменяет локальную базу и папку файлов версией с Диска.
- Перед скачиванием создаётся резервная копия.
- Слияния изменений нет: не редактируйте две копии одновременно.
- Версия увеличивается при каждой отправке.
- В манифесте хранятся версия, устройство, время, SHA-256 базы, размер,
  версия схемы и число вложений.

### 6.2 Провайдеры

| Провайдер | Что нужно | Где лежат файлы |
|---|---|---|
| Папка Google Диска | Google Drive для компьютера | Выбранная синхронизируемая папка |
| Google Drive API | OAuth Client ID/Secret, подключение в браузере | Папка `Tasker` на Google Диске |
| Яндекс Диск | OAuth-токен | Папка приложения `app:/` на Яндекс Диске |

Подробные инструкции, права доступа и ошибки — в
[connection.md](connection.md).

### 6.3 Быстрая синхронизация

Кнопки над «Настройками» используют уже сохранённый способ. Если способ
не настроен, виджет открывает настройки. После отправки виджет обновляет
версию; после скачивания страница перезагружается.

## 7. HTTP API

Сервер слушает только локальный интерфейс. Все запросы к API проходят
проверку `Host` и, для изменяющих методов, `Origin`. Аутентификации нет,
поэтому не открывайте порт в интернет.

Основные маршруты:

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/bootstrap` | Проекты + информация + версия |
| GET | `/api/info` | Состояние базы и синхронизации |
| GET | `/api/calendar?start=...&end=...` | Задачи периода |
| GET | `/api/projects` | Список проектов |
| POST | `/api/projects` | Создать проект |
| PATCH | `/api/projects/<id>` | Изменить проект |
| DELETE | `/api/projects/<id>` | Удалить проект |
| GET/POST | `/api/projects/<id>/tasks` | Задачи проекта |
| PATCH/DELETE | `/api/tasks/<id>` | Задача |
| POST | `/api/tasks/<id>/move` | Переместить по колонкам |
| POST | `/api/calendar/order` | Сохранить порядок строк |
| GET/POST | `/api/projects/<id>/messages` | Заметки |
| PATCH/DELETE | `/api/messages/<id>` | Заметка |
| GET | `/api/attachments/<id>` | Скачать вложение |
| POST | `/api/backup` | Создать ZIP-копию |
| GET | `/api/backup/download` | Скачать ZIP |
| POST | `/api/db/switch` | Открыть другую базу |
| GET | `/api/sync/status` | Статус синхронизации |
| POST | `/api/sync/send` | Отправить на Диск |
| POST | `/api/sync/receive` | Скачать с Диска |
| POST | `/api/yandex/connect` | Проверить и сохранить токен Яндекса |
| POST | `/api/drive/auth/start` | Начать OAuth Google |
| POST | `/api/drive/settings` | Сохранить Google-клиент |
| POST | `/api/drive/disconnect` | Отключить Google |
| POST | `/api/yandex/disconnect` | Отключить Яндекс |

`GET /api/sync/status?refresh=1` дополнительно запрашивает актуальный
манифест у Google Drive API или Яндекс Диска. Обычный `GET /api/info`
не ходит в сеть.

## 8. Архитектура

- **Python stdlib** — без Flask, FastAPI и внешних зависимостей.
- `ThreadingHTTPServer` — локальный HTTP-сервер.
- Одно долгоживущее соединение SQLite; все операции сериализуются `RLock`.
- `PRAGMA journal_mode=DELETE`, `synchronous=FULL` — один файл базы после
  закрытия.
- Frontend — обычные HTML, CSS и ES-модули без сборщика.
- Состояние вкладки синхронизируется через SSE.
- `BrowserLifecycle` завершает сервер после закрытия последней вкладки.
- Настройки лежат отдельно от базы в `%APPDATA%\Tasker\settings.json`.

Ключевые модули:

- `tasker/db.py` — схема, задачи, заметки, файлы, резервные копии;
- `tasker/http.py` — API и статика;
- `tasker/sync.py` — обмен через локальную папку;
- `tasker/gdrive.py` — Google Drive API;
- `tasker/yandex.py` — Яндекс Диск;
- `tasker/filedialog.py` — системный выбор файла/папки Windows;
- `tasker/settings.py` — пользовательские настройки;
- `web/js/app.js` — состояние интерфейса;
- `web/js/calendar.js` — календарь и упаковка строк;
- `web/js/board.js` — канбан.

## 9. Настройки и параметры запуска

### 9.1 Файл настроек

`%APPDATA%\Tasker\settings.json`:

- `db_path` — путь к базе;
- `calendar` — видимость проектов, выполненных задач и выходных;
- `sync_mode` — `folder`, `drive` или `yandex`;
- `sync_folder` — папка для режима folder;
- `device_name` — имя устройства;
- `last_sync` — последняя синхронизация;
- `drive_*` — Google OAuth-клиент, refresh/access token, ID папок;
- `yandex_*` — токен, состояние и размеры Яндекс Диска.

Токены хранятся в открытом виде. Защищайте профиль Windows.

### 9.2 Переменные окружения

| Переменная | Назначение |
|---|---|
| `TASKER_CONFIG_DIR` | Каталог settings.json вместо `%APPDATA%\Tasker` |
| `TASKER_DB` | Путь к базе по умолчанию |
| `TASKER_HOST` | Адрес сервера |
| `TASKER_PORT` | Начальный порт |

### 9.3 Параметры командной строки

| Параметр | Назначение |
|---|---|
| `--port N` | Порт, по умолчанию 8765 |
| `--host ADDR` | Адрес прослушивания, по умолчанию `127.0.0.1` |
| `--db PATH` | Путь к базе, приоритетнее настроек |
| `--no-browser` | Не открывать браузер |
| `--auto-shutdown` | Завершать после закрытия последней вкладки |
| `--verbose` | Печатать HTTP-запросы |
| `--version` | Показать версию |

## 10. Безопасность

- Сервер по умолчанию слушает только `127.0.0.1`.
- Проверяются `Host` и `Origin`, чтобы сторонние сайты не могли обращаться
  к локальному API через DNS rebinding.
- API не имеет пароля; не открывайте порт в интернет и не используйте
  `--host 0.0.0.0` без доверенной сети.
- OAuth-токены и client secret лежат в `settings.json` в открытом виде.
- Токен Яндекса — фактически пароль к папке приложения. Не публикуйте его.
- Отозвать доступ можно в Яндекс ID или в настройках соответствующего
  провайдера.
- ZIP-копии не зашифрованы. Храните их в защищённом месте.

## 11. Сборка exe

Требования: Windows x64, Python 3.10+.

```powershell
build_exe.bat
```

Скрипт создаёт временное окружение, ставит PyInstaller и собирает
`Tasker.exe` без консоли. Иконка и метаданные версии — в `assets/`.

Готовая версия: **1.11.0**.

## 13. Ограничения

- Один пользователь и один экземпляр приложения на одну базу.
- Нет автоматической синхронизации и слияния изменений.
- Конфликты решаются вручную: отправить или скачать, сохранив копию.
- Нет поиска по всем проектам и напоминаний о сроках.
- Нет повторяющихся задач и совместной работы в реальном времени.
- Windows-сборка только x64; на других ОС запускайте из исходников.
- Google Drive API и Яндекс Диск требуют собственного OAuth-приложения.
- У Яндекс Диска в режиме токена нет автоматического refresh.
- Ограничения облака (квота, размер файла, лимит загрузок) зависят от
  тарифа провайдера.

## 14. Диагностика

### Не открывается браузер

Проверьте `%APPDATA%\Tasker\tasker.log`. Убедитесь, что порт 8765 или
следующий свободный не занят. Запустите с `--verbose` из консоли.

### База не открывается

Проверьте права на папку и свободное место. Укажите другой путь через
`--db` или в настройках.

### Синхронизация не настроена

Откройте настройки и выберите способ. Для folder нужна папка, для
Google API — Client ID/Secret, для Яндекса — OAuth-токен.

### Яндекс возвращает 400 «Неизвестно приложение с таким client_id»

Ссылка собрана с неверным ClientID. Подробная инструкция и чек-лист —
в [connection.md](connection.md#81-яндекс-400-неизвестно-приложение-с-таким-client_id).

### Ошибка токена Яндекса

Токен истёк, скопирован не полностью или у приложения нет права
`cloud_api:disk.app_folder`. Получите новый токен.

### После скачивания пропали локальные изменения

Так работает замена: «Скачать» заменяет базу. Перед заменой создаётся
копия в `data/backups/`. Восстановите её вручную при необходимости.
